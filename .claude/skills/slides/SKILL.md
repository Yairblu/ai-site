# ckm:slides Overview

This is a Claude Agent designed to create strategic HTML presentations.

**Primary Purpose:** Generate data-driven presentation slides using HTML, Chart.js visualizations, and design patterns optimized for marketing and pitch decks.

**Core Capability:**
The tool accepts a topic and slide count as arguments, then produces presentations with responsive layouts and strategic content structure.

**Available Resources:**
The agent references four knowledge bases:
- Layout Patterns (presentation structure)
- HTML Template (technical foundation)
- Copywriting Formulas (persuasive content)
- Slide Strategies (contextual approaches)

**How It Works:**
The system parses your command, identifies the subcommand (currently "create" is documented), retrieves relevant reference materials, and executes the presentation generation using your remaining arguments.

**Best Use Cases:**
- Marketing presentations and investor pitches
- Visualizations leveraging Chart.js
- Multi-slide decks requiring consistent design
- Copywriting-optimized messaging strategies

To use this agent, provide a topic and desired slide count, and it will construct a complete HTML presentation following strategic design and persuasion principles.
