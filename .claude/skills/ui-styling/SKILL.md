# UI Styling Skill Overview

This is a comprehensive skill for building accessible, visually refined user interfaces using three integrated layers:

## Core Stack

**Component Layer**: shadcn/ui provides "pre-built accessible components via Radix UI primitives" with a copy-paste distribution model and TypeScript support.

**Styling Layer**: Tailwind CSS delivers utility-first styling with "build-time processing with zero runtime overhead" and mobile-first responsive design.

**Visual Design Layer**: Canvas-based approaches enable sophisticated visual communication emphasizing design over text.

## Key Capabilities

The skill applies to React frameworks (Next.js, Vite, Remix, Astro) for building forms, navigation, data tables, dialogs, and complex UI patterns. It supports dark mode implementation, design system establishment, and rapid prototyping.

## Quick Implementation

Setup involves running `npx shadcn@latest init` for component configuration, then adding specific components like buttons and cards. Components combine with Tailwind utilities for styling, as shown in the dashboard example with responsive grid layouts and hover effects.

## Reference Materials

Detailed guidance covers component catalogs, theming customization, accessibility patterns (ARIA, keyboard navigation, focus management), Tailwind utilities, responsive breakpoints, and canvas design philosophy emphasizing "minimal text, maximum visual impact."

## Best Practices

The approach emphasizes component composition, utility-first styling, mobile-first responsive design, accessibility-first implementation, consistent design tokens, dark mode consistency, TypeScript safety, and treating UI development as expert craftsmanship.
